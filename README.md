# Old ML Projects - Complete Code Documentation

This repository contains two comprehensive machine learning projects with detailed line-by-line code explanations.

## Projects Overview

### 1. Fashion MNIST CNN Classification
- **Algorithm**: Convolutional Neural Network (CNN)
- **Dataset**: Fashion MNIST (70,000 clothing images)
- **Task**: Multi-class classification (10 clothing categories)
- **Environment**: Google Colab
- **Reference**: [Machine Learning Mastery CNN Tutorial](https://machinelearningmastery.com/how-to-develop-a-cnn-from-scratch-for-fashion-mnist-clothing-classification/)

### 2. Breast Cancer SVM Classification
- **Algorithm**: Support Vector Machine (SVM)
- **Dataset**: Breast Cancer Coimbra (116 clinical samples)
- **Task**: Binary classification (healthy vs. cancer)
- **Environment**: Google Colab
- **Reference**: [UCI Breast Cancer Coimbra Dataset](https://archive.ics.uci.edu/ml/datasets/Breast+Cancer+Coimbra)

## Original Project Description

**Fashion MNIST Classification**: The code is implemented for classifying the fashion Mnist dataset. The deep learning architecture used in this project is CNN. I used google Colab environment for implementing this code.

**Breast Cancer SVM Project**: In this project we want to classify a two class dataset called Breast Cancer Coimbra dataset which one class is related to patients with breast cancers and the other class is related to healthy controls. The code is implemented in google colab and you can see more explanation about the code as you open it. The csv format of data is also attached.
